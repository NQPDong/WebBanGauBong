# Teddy Bear E-commerce Website (WebBanGauBong)

A professional e-commerce platform for selling plush toys, built with **ASP.NET MVC** and **C#**. This project demonstrates a full-stack development approach, focusing on clean architecture and smooth user experience.

---

## Key Features

### Customer Side
* **Product Catalog:** Browse various categories of teddy bears with high-quality images.
* **Smart Filtering:** Filter products by price, size, and category.
* **Shopping Cart:** Add, remove, and update item quantities seamlessly.
* **Authentication:** Secure user login and registration system.
* **Order Management:** Track order history and status.

### Admin Dashboard
* **Product Management:** Full CRUD (Create, Read, Update, Delete) functionality for products.
* **Inventory Control:** Track stock levels and product details.
* **Order Tracking:** View and process customer orders.

---

## Tech Stack

* **Backend:** C# (.NET Framework), ASP.NET MVC, Entity Framework.
* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap.
* **Database:** Microsoft SQL Server.
* **Development Tools:** Visual Studio, Git, SQL Server Management Studio (SSMS).

---

## Project Structure

```text

├── Views/            # Razor views (UI)
```
